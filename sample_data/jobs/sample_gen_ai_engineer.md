# Sample Job Description: Generative AI Engineer

**Company**: TechCorp AI
**Location**: Remote (US)
**Level**: Mid-Senior

## About the Role

We're looking for a Generative AI Engineer to design and build production LLM-powered applications. You'll work across the full stack — from prompt engineering and RAG pipeline design to API development and deployment.

## Requirements

### Must Have
- 2+ years building applications with LLMs (GPT-4, Claude, Gemini, etc.)
- Experience with RAG architectures: vector databases, embedding models, chunking strategies
- Proficiency in Python and at least one web framework (FastAPI, Flask, Django)
- Experience with LLM orchestration frameworks (LangChain, LangGraph, or similar)
- Understanding of prompt engineering techniques and structured output generation
- Experience deploying ML/AI applications to production (AWS, GCP, or Azure)

### Preferred
- Experience with fine-tuning or RLHF workflows
- Familiarity with LLM evaluation and benchmarking methodologies
- Experience building agent systems with tool use / function calling
- Knowledge of vector databases (Pinecone, Weaviate, pgvector, ChromaDB)
- Frontend experience (React, TypeScript) for building demo UIs
- Experience with observability tools for LLM applications (LangSmith, Langfuse)

### Bonus
- Contributions to open-source AI/ML projects
- Experience with multimodal models (vision, audio)
- Background in a non-CS domain that gives unique perspective on AI applications

## What You'll Do
- Design and implement RAG pipelines for domain-specific knowledge retrieval
- Build and maintain agent workflows for complex multi-step tasks
- Develop evaluation frameworks to measure output quality and reliability
- Collaborate with product and design to ship user-facing AI features
- Optimize LLM usage for cost, latency, and quality tradeoffs

## Tech Stack
- Python, FastAPI, LangChain/LangGraph
- PostgreSQL, pgvector
- GCP (Cloud Run, Vertex AI)
- React/TypeScript for internal tools
- GitHub Actions CI/CD
