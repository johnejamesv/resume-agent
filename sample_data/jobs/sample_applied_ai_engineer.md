# Sample Job Description: Applied AI Engineer

**Company**: DroneOps Inc.
**Location**: San Mateo, CA (Hybrid)
**Level**: Senior

## About the Role

We're hiring an Applied AI Engineer to build intelligent systems that process real-world sensor data from autonomous platforms. You'll work at the intersection of software engineering, data engineering, and machine learning — turning messy field data into reliable automated decisions.

## Requirements

### Must Have
- 3+ years of software engineering experience with Python
- Experience building data pipelines that process sensor, telemetry, or geospatial data
- Familiarity with cloud infrastructure (GCP, AWS, or Azure) and containerized deployments
- Experience with SQL databases and data modeling
- Strong understanding of software engineering fundamentals: testing, CI/CD, version control

### Preferred
- Experience with computer vision or image processing pipelines
- Background in a field that involves physical systems (robotics, aerospace, manufacturing, energy)
- Experience with heuristic or rule-based classification systems
- Familiarity with AI/ML frameworks (PyTorch, TensorFlow) and LLM APIs
- Experience building internal tools or dashboards (React, TypeScript)

### Bonus
- FAA Part 107 or equivalent drone pilot certification
- Experience with drone data, photogrammetry, or 3D modeling pipelines
- Knowledge of telecom infrastructure inspection workflows

## What You'll Do
- Build and maintain data pipelines that ingest and classify sensor data from autonomous platforms
- Design classification and QA systems that encode domain expertise into software rules
- Integrate AI/ML models for tasks where heuristic approaches are insufficient
- Work with field operations teams to understand data quality challenges
- Deploy and monitor production services on cloud infrastructure

## Tech Stack
- Python, FastAPI
- PostgreSQL, Cloud SQL
- GCP (Cloud Run, Cloud Storage), Terraform
- Docker, GitHub Actions
- React/TypeScript for internal dashboards
